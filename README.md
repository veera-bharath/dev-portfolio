# Veera Bharath — Dev Portfolio

Personal portfolio built with React, Three.js, and Framer Motion. Features a 3D animated bee mascot that guides visitors through each section with section-aware dialogue and auto-scroll.

**Live:** https://veera-bharath.github.io/dev-portfolio/

## Tech Stack

- React 19 + Vite
- Three.js via `@react-three/fiber`
- Framer Motion
- Custom CSS utilities (no Tailwind runtime)

## Sections

- **Hero** — Intro with animated 3D background and bee conversation
- **About** — Overview and specialisation cards
- **Experience** — Work timeline at Nivi Software Solutions
- **Tech** — Dual-row marquee of tools and technologies
- **Projects** — Side projects with links to GitHub
- **Contact** — Reach-out form

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` automatically build and deploy to GitHub Pages via the included workflow.
