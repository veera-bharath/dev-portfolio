# Dev Portfolio

Personal developer portfolio built with React, Three.js, and Framer Motion — featuring a 3D animated hero, interactive bee guide, and a glassmorphism design system.

## Status

| Platform | Status |
|----------|--------|
| Desktop  | ✅ Fully working |
| Mobile   | 🚧 Responsiveness in progress |

## Tech Stack

- **React 19** + **React Router v7**
- **Three.js** / **@react-three/fiber** — 3D canvas backgrounds
- **Framer Motion** — scroll-triggered and layout animations
- **Vite** — build tool
- Custom utility-first CSS (no Tailwind)

## Features

- Interactive bee guide that walks through the portfolio
- Glassmorphism cards with neon cyan / purple accent palette
- Horizontal scrolling project carousel
- Animated tech marquee rows
- Scroll-aware navbar with profile image transition
